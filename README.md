# 🎂 Sorpresa de Cumpleaños para Cynthia ✨
### *13 de Septiembre de 2026*

Una experiencia web interactiva, romántica y festiva creada especialmente como sorpresa de cumpleaños para **Cynthia**. Desarrollada con tecnologías web modernas, diseño artesanal inspirado en motivos festivos, animaciones interactivas, música retro chiptune en tiempo real y generación de video cinematográfico.

---

## 🌟 Características Principales

### 💖 1. Desbloqueo Interactivo con Corazón
- Interacción táctil progresiva: cada pulsación en el corazón aumenta el medidor de progreso con mensajes cariñosos y notas sonoras retro.
- Al alcanzar el **100%**, se activa una explosión festiva de confetti multicolor y se desbloquea la celebración completa.

### 📸 2. Álbum Polaroid de Recuerdos
- Carrusel de fotos táctil con diseño de marco Polaroid físico, sombras realistas y motivos festivos (guirnalda de banderitas mexicanas y rayos estrellados).
- **29 fotografías** de momentos inolvidables optimizadas en formato **WebP** de última generación para carga instantánea y máxima fluidez.
- Encuadre inteligente de rostros y visor lightbox ampliado para disfrutar cada foto al detalle.

### ✉️ 3. Sobre Artesanal y Carta Secreta
- Sobre tridimensional interactivo con textura arena/dorada y sello de lacre rojo (*"Descúbrelo"*).
- Al interactuar, la solapa se abre y despliega una carta en pergamino con una emotiva dedicatoria en caligrafía personalizada.

### 🥂 4. Brindis de Cumpleaños & Foto Especial
- Animación interactiva de copas de champagne con destellos dorados y sonido cristalino que reacciona al scroll de la página.
- Marco conmemorativo con la foto especial de pareja y la dedicatoria: *“Gracias por compartir tu vida conmigo”*.

### 🎬 5. Generador Cinematográfico de Video ("Guardar este momento")
- Motor de renderizado en Canvas 2D + MediaRecorder integrado en el navegador.
- Genera en tiempo real una **pieza de video vertical 9:16 (720x1280)** de **~48 segundos** que recorre las fases de la web (Intro, Carrusel Polaroid, Carta Secreta, Brindis y Cierre).
- Incluye sincronización de audio limpia y opciones directas para descargar en MP4 o compartir en WhatsApp e Instagram Stories.

### 👾 6. Motor de Audio Retro 8-Bit
- Banda sonora de cumpleaños sintetizada en tiempo real mediante la **Web Audio API** nativa (ondas cuadradas y triangulares).
- Botón flotante para activar o pausar la música en cualquier momento.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Estilos:** [Vanilla CSS](https://developer.mozilla.org/es/docs/Web/CSS) + [Tailwind CSS](https://tailwindcss.com/)
- **Efectos y Animaciones:** [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti) + CSS 3D Transforms
- **Audio:** Web Audio API (sintetizador chiptune nativo)
- **Video:** HTML5 Canvas 2D + MediaStream Recording API
- **Optimización de Imágenes:** [Sharp](https://sharp.pixelplumbing.com/) (conversión por lotes a WebP y corrección EXIF)

## 🚀 Instalación y Puesta en Marcha

Si deseas ejecutar el proyecto localmente:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/manueladolfo/Cynthia-Cumpleanos-2026.git
   cd Cynthia-Cumpleanos-2026
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
